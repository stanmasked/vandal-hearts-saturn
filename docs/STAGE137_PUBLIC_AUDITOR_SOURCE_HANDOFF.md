# Stage137 — public-only audit module handoff for a private Stage124 capture

## Why
The actual Stage135 replacement Stage124 pair is running against authenticated
owner-owned original Saturn source media inside a restricted local runtime.
It must be independently evaluated with precisely the already established
Stage126 and Stage129 auditors before any Stage125 original-media tenth-C run.

Stage137 packages the exact versioned ROM-free public Python modules in the
repository's tools/ directory, after running the existing invented-only Stage128
and Stage129 tests. The exported compressed TAR.GZIP contains **only .py
source files in tools/**; it does not include private source discs, screenshot
PNGs, archive payloads, original-game logs, private hash manifests, cloud
tokens, secrets or config. This is a short-lived one-day GitHub artifact to
transfer the authoritative audit implementation into the authorized private
runtime where the actual capture archive already resides.

After a successful public CI run, download the source-only artifact ZIP,
independently verify its job-log SHA-256, inspect TAR paths and extract
to an isolated local audit directory. Run the auditor modules against the
locally pinned private archive and its separately verified fingerprint;
never send the archive to GitHub. The Stage126 structural integrity result
is not a cloud provenance attestation; the Stage129 paired semantic audit
is not evidence of tactical battle or player control.

## Remaining gates
The replacement Stage135 control and intervention runs must each finish
108000 frames with 900 checkpoints, canonical PAD receipts, good final CD,
SH2/video and framebuffer diagnostics, and 799 identical pre-ninth
checkpoints. The resulting new archive must be uploaded to owner-only Drive
and downloaded independently for digest and member-level verification.
Do not mint any Stage125 private receipt before those steps succeed and
Drive ownership/permissions are authenticated.

The historical Stage124 archive remains absent and must not be conflated
with the NEW Stage135 experiment. Public GitHub Actions continue to run
only ROM-free tests.
